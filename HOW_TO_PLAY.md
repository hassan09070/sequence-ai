# 🎮 HOW TO CLONE AND PLAY - Quick Guide

## 📥 Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/hassan09070/projectAI.git
cd projectAI
```

## ✅ Step 2: Verify Installation (Optional but Recommended)

Run the tests to make sure everything works:

```bash
python3 tests.py
```

You should see:
```
✓ All tests passed! (28/28)
```

## 🎮 Step 3: Start Playing!

Simply run:

```bash
python3 main.py
```

## 🎯 Choose Your Game Mode

You'll see:
```
1. Human vs Human    - Play with a friend
2. Human vs AI       - Challenge the computer  
3. AI vs AI (Demo)   - Watch AI players compete
```

## 🤖 Select AI Difficulty (if playing vs AI)

```
1. Easy    - Perfect for beginners
2. Medium  - Balanced gameplay
3. Hard    - Real challenge
4. Expert  - Maximum difficulty
```

## 🎲 Playing the Game

1. **See your hand** - Cards you can play
2. **Pick a card** - Enter the number
3. **Choose position** - Where to place your chip
4. **Win!** - Get 2 sequences (5 in a row)

## 💡 Special Cards

- **♥J, ♦J (Two-eyed Jacks)** - Wild! Place anywhere
- **♠J, ♣J (One-eyed Jacks)** - Remove opponent's chip

## 🎯 Goal

Create **2 sequences** before your opponent!  
(A sequence = 5 connected chips in a row)

## 🆘 Need Help?

- **Quit game**: Press `Ctrl+C`
- **See board**: Enter `0` when selecting a card
- **Read full rules**: See [README.md](README.md)
